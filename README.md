# Artimoshka Ai — Android-приложение (WebView)

Тонкая оболочка над генератором https://perchance.org/artimoshka-ai.
Сам генератор грузится из интернета, поэтому APK **не нужно пересобирать**
при обновлениях генератора — новые кнопки и функции появятся сами.

Что умеет оболочка:
- открывает генератор на весь экран;
- «Своё фото»: выбор из галереи или съёмка камерой;
- сохранение снимков в «Загрузки» (через мост `ArtimoshkaNative`);
- кнопка «назад» листает историю страниц, внешние ссылки уходят в браузер.

## Сборка APK (бесплатно, без установки программ)

1. Создайте на https://github.com/new пустой репозиторий.
2. Загрузите туда **всё содержимое этой папки** (кнопка «Add file → Upload files»).
3. Откройте вкладку **Actions** → выберите **Build APK** → **Run workflow**
   (при пуше в main сборка стартует сама).
4. Через несколько минут заберите файл **Artimoshka-Ai.apk**
   из артефактов (`Artimoshka-Ai-apk`).
5. Перекиньте APK на телефон и установите
   (разрешите «установку из неизвестных источников»).

## Сборка в Android Studio

Откройте эту папку как проект, дождитесь синхронизации Gradle
и соберите **Build → Build APK(s)**. Готовый файл:
`app/build/outputs/apk/debug/app-debug.apk`.

## Смена адреса генератора

Адрес зашит в `MainActivity.java` (`APP_URL`). Если генератор
переименуют — поменяйте строку и пересоберите APK.
